# ConflictBench 한국어 빠른 시작

Syncthing이 만든 충돌 파일을 비교하고, 사용자가 직접 선택한 결과를 별도 백업과 함께 적용하는 로컬 데스크톱 앱입니다. Syncthing 계정·API 키는 필요하지 않습니다.

시스템 언어가 한국어면 화면도 한국어로 나옵니다. 영어로 보려면 `ConflictBench --language en`으로 실행하세요. 아래 단추 이름은 한국어 화면 기준입니다.

## 먼저 데모로 연습하기

압축을 푼 뒤 ConflictBench를 실행하고 **데모 실행**을 누르세요. 한글 텍스트, 그림, 바이너리 예제가 표시됩니다. 실제 사용자 파일은 사용하지 않습니다. 데모 폴더와 백업은 앱 종료 시 삭제되므로, 실제 파일 백업용으로 사용하지 마세요.

## 실제 폴더 처리 순서

1. **폴더 열기**에서 확인할 로컬 동기화 폴더 하나를 고릅니다. 검색 단계는 읽기 전용입니다.
2. 왼쪽 원본 이름 아래의 충돌본을 선택합니다. 충돌본마다 Syncthing 파일 이름에 들어 있는 날짜, 시각, 기기가 표시됩니다(예: *충돌본 · 26. 10. 1. 09:15 · 기기 ABCDEFG*). **나란히 보기**에서 바뀐 줄이 색으로 표시됩니다. 빨간 줄은 원본에만, 초록 줄은 충돌본에만 있습니다. **텍스트 차이**에서는 `-`, `+`로 볼 수 있습니다.
3. 원하는 결정을 선택합니다.
   - **원본 유지**: 원본을 유지하고 선택한 충돌본을 외부 백업으로 보관합니다.
   - **충돌본 사용**: 원본을 선택한 충돌본으로 교체합니다. 이전 두 버전은 외부 백업에 남습니다.
   - **둘 다 유지**: 원본과 확장자가 유지된 별도 이름의 충돌본을 모두 남깁니다.
4. **계획 확인**을 누르고 모든 동기화 폴더 밖의 개인용 로컬 백업 폴더를 고릅니다.
5. Syncthing에서 해당 폴더를 일시정지하고 파일을 쓰는 편집기·프로그램을 닫습니다.
6. 계획 맨 위의 한 줄 요약(예: *여행 계획.txt을(를) 유지합니다. 충돌본은 백업 폴더로 옮깁니다.*)과 백업 위치를 확인하고, 두 확인란을 체크한 뒤 **백업하고 적용**을 누릅니다. 전체 경로와 SHA-256은 **전체 경로와 SHA-256 보기**에서 볼 수 있습니다.
7. 결과를 확인한 다음 동기화를 다시 시작합니다.

원본과 내용이 완전히 같은 충돌본에는 *내용 같음*이 붙습니다. **내용 같은 충돌본 정리**를 누르면 이런 충돌본을 한 번 확인으로 모두 백업 폴더에 보관합니다. 하나씩 따로 기록이 남으므로 각각 되돌릴 수 있습니다.

## 중단·실패·되돌리기

**기록 / 복구**에서 이전에 사용한 백업 폴더를 엽니다. 처리 단계와 이력을 확인한 뒤, 동기화·편집기를 멈추고 선택한 기록의 **선택한 작업 되돌리기 / 복구**를 실행합니다. 현재 파일과 백업의 해시가 예상된 상태일 때만 복구합니다. 이후 파일이 바뀌었다면 덮어쓰지 않고 거절합니다. 이 기능은 다른 장치에서 이미 전파되거나 수정된 내용을 되돌려 준다는 뜻이 아닙니다.

## 알아둘 제한

- 여러 파일이 한 번에 원자적으로 바뀌는 것은 아닙니다. 중간 상태가 기록되며 복구 절차를 사용합니다.
- 해시 검증만으로 다른 프로그램과의 모든 경쟁 상태를 막을 수 없으므로 일시정지가 필수입니다.
- 로컬 일반 파일만 지원합니다. 심볼릭 링크, 원본이 없는 충돌, 대소문자 충돌, 네트워크 드라이브, 클라우드 가상 파일은 지원 범위 밖입니다.
- 파일당 256 MiB, 검색 100,000개 항목·1,000개 충돌쌍 제한이 있습니다. UTF-8 텍스트 미리보기 1 MiB, 줄 차이 1,200줄 제한입니다.
- POSIX 기본 권한은 다루지만 ACL·확장 속성·macOS 리소스 포크 보존은 보장하지 않습니다. 백업 폴더는 본인만 접근할 수 있는 곳을 고르세요.
- 외부 비교 도구는 신뢰하는 실행 파일을 직접 고릅니다. 인수는 한 줄에 하나씩 입력하며 `{original}`, `{conflict}`는 검증된 임시 사본으로 치환됩니다. 셸 명령은 실행하지 않습니다.
- 배포 파일은 코드 서명·macOS 공증이 없습니다. 공개된 SHA-256 체크섬을 확인하세요.

문제 보고에 개인 문서나 백업 원문을 첨부하지 마세요. 운영체제, 앱 버전, 민감한 경로를 가린 오류, 재현용 가짜 파일이면 충분합니다.
